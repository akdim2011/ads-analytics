# AdsAnalytics APK (GitHub Actions)

يبني GitHub ملف APK لك في السحابة، بدون Android Studio.

## الخطوات
1. أنشئ حساباً مجانياً على github.com ثم New repository (اسم مثل ads-analytics).
2. ارفع محتوى هذا المجلد كاملاً إلى المستودع (Add file ثم Upload files)، مع المجلد المخفي `.github`.
   إن لم يُرفع `.github` فأنشئ الملف يدوياً: Add file ثم Create new file، واكتب في الاسم
   `.github/workflows/build-apk.yml` والصق محتوى الملف.
3. افتح تبويب Actions ثم Build Android APK ثم Run workflow (يبدأ تلقائياً أيضاً عند الرفع). يستغرق 5 إلى 10 دقائق.
4. عند ظهور علامة خضراء افتح التشغيل، وفي Artifacts نزّل AdsAnalytics-APK، ثم فك الضغط لتجد app-debug.apk.
5. انقله إلى الهاتف وافتحه، ووافق على التثبيت من مصادر غير معروفة.

## ملاحظات
- غيّر `appId` في capacitor.config.json قبل أول تثبيت إن أردت معرّفاً خاصاً (تغييره لاحقاً يجعله تطبيقاً مختلفاً).
- الملف موقّع بتوقيع التطوير، وهذا يكفي للتثبيت المباشر. النشر على Play Store يحتاج بناء AAB موقّعاً بمفتاحك الخاص.
- إن فشل البناء (علامة حمراء) افتح الخطوة الفاشلة وانسخ نص الخطأ.
- الخطوط تُحمَّل من الإنترنت، وبدونه يستخدم التطبيق خط النظام.
